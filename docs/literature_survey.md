# Preliminary Literature Review

## Purpose
This document records preliminary literature relevant to comparing CPU and GPU execution for the Conjugate Gradient method.

## Paper 1: Parallel Preconditioned Conjugate Gradient Algorithm on GPU
**Authors:** Rudi Helfenstein and Jonas Koko  
**Published:** 2012  
**DOI:** https://doi.org/10.1016/j.cam.2011.04.025

### Summary
This paper studies GPU implementations of the Conjugate Gradient and preconditioned Conjugate Gradient methods for sparse linear systems. It discusses sparse matrix storage and reports performance comparisons between CPU and GPU implementations.

### Relevance
This is directly related to the selected project because it investigates CG computation on CPU and GPU platforms.

### Limitation for the Current Project
The hardware evaluated in this older study differs from modern computing environments. Its performance measurements should not be treated as predictions of current hardware performance.
